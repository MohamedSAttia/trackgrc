## النشر على Vercel
1. ارفع محتوى هذا المجلد إلى مستودع GitHub.
2. Vercel → Add New → Project → اختر المستودع → Deploy (بدون إعدادات بناء).

بدون المفتاح تعمل كل الوحدات؛ ويعمل مساعد الأكاديمية من قاعدة معرفته الداخلية، ويعرض المقيّم توصيات محسوبة.
البيانات تُحفظ في متصفح المستخدم فقط.

## الوصول المؤقت وحماية المحتوى
- أي شخص يفتح رابط الموقع يحصل على **ساعة واحدة** من لحظة أول زيارة، ثم تُغلق المنصّة له تلقائيًا وتظهر له رسالة الدورة ورابط التسجيل.
- لا يحتاج أي إعداد؛ ويمكن (اختياريًا) إضافة `LINK_SECRET` في Vercel بنص عشوائي طويل لتقوية التوقيع.
- الحماية داخل الصفحات: منع النسخ والقص والتحديد والقائمة اليمنى واختصارات الحفظ والطباعة وأدوات المطوّر، وعلامة مائية، وإخفاء المحتوى عند مغادرة الصفحة، وعدّاد للوقت المتبقي.
- حجب زواحف الذكاء الاصطناعي (GPTBot وClaudeBot وغيرها) و`robots.txt` ورؤوس `noai`.

## الذكاء الاصطناعي
المستشار الذكي في «المقيّم الذكي» ومساعد «الأكاديمية» يعملان **داخليًا بدون أي مفتاح**.
(اختياري) إضافة `ANTHROPIC_API_KEY` تُفعّل إجابات توليدية أعمق في مساعد الأكاديمية.
